A single-line safety warning label that should come printed on every human being, written in the deadpan wording of a real printed label: it warns that this human may start sentences with "no offense" and finish them with one anyway. Pure Python standard library; the program writes the 90-character label to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
